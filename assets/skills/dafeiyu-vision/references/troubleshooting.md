# 识图排障

按"报错原文"找，一条一条试。**先看状态，再谈修复**：

```js
vision_web_status({ site: 'doubao' })   // 登录态
```

## 一、`识图未开启`

设置页「肥鱼识图」总开关没开。工具/路由是实时读配置的，**开完不用重启**；
但系统提示里那段「识图能力」是启动时注入的，那种情况下模型可能不知道有识图——重启一次即可。

## 二、`还没配置 API Key`

走的是 API 那路。两种修法：
1. 填 key（接口地址 + key + 模型名 + 协议）；
2. 打开「白嫖豆包」——不用 key，但要先去「网页版（免 key）」里登录一次。

## 三、`<站点>没有登录`

1. `vision_web_status` 确认（`loggedIn: false`）；
2. 用户在电脑前 → `vision_web_login({ site })`，会弹有头窗口，等用户登完（最多 150 秒）；
3. 用户不在 → 直接告诉用户"回来点一下登录"，别反复调工具。

## 四、`页面没加载出来` / `找不到上传入口` / `点了上传但没出现文件输入框`

前端改版了。选择器集中在 `src/vision/web/sites.ts` 顶部那张 `DOUBAO` / `GEMINI` 表里，
改选择器即可，不要动流程代码。改完跑 `npm test`（有假 CDP 客户端的用例钉流程）。

## 五、`消息没发出去（输入框里还留着字）`

- 站点侧风控/限流，或「发送」按钮换了位置；
- 手动开一次有头窗口（设置页勾「识图时弹出浏览器窗口」），看是不是要人工过验证码；
- 别连着重试三次以上——可能把账号打进风控名单。

## 六、`没有返回可读的回答（等了 N 秒）。截图：…`

会落一张截图到临时目录（路径在错误里）。看截图判断：
- 停在登录页/验证码 → 见第三条、第五条；
- 有回答但抽不出来 → 选择器失效，见第四条；
- 站点自己报错（例如 Gemini 的「出了点问题」）→ 站点/账号侧问题，告诉用户，别修代码。

## 七、登录态"莫名其妙又没了"

按这个顺序查：
1. 是不是被**强杀**过浏览器（任务管理器结束进程）——刚落的 cookie 会丢；
2. 是不是用**无头 UA** 发过图（旧版本行为）——豆包会作废登录态。0.1.3 起已修；
3. 换台机器/换网络后要求重新验证——正常，再登一次。

## 八、`切不到项目「xxx」`

- 项目名要跟网页侧栏「项目」下面**一字不差**（含空格、全半角）；
- 项目是在别的账号下建的 → 当前登录账号看不到它；
- Gemini 不支持项目，配了会被忽略（不报错）。

## 九、复合模式只回了一段

看末尾那句 `（另一路没成，已忽略：…）`：
- `外挂模型 … API Key` → key 没填；
- `网页版…没有登录` → 见第三条；
- 两路都挂 → 报错里会同时带两边原因。
